# 行情监控（A股 / 伦敦金现 / 伦铜）

仿 [btcinfo](https://github.com/xiaoheiwo/btcinfo) 的 Windows 桌面悬浮行情小工具。
界面只保留三列：**代码后 4 位、价格、涨跌幅**；宋体点阵字形、浅灰色、无标题栏、无底部提示、透明背景。

## 功能

- 自选列表：A 股、指数、伦敦金现、伦铜混排，右键「设置」随时增删
- 3 秒自动刷新（可调 2–300 秒）
- 只有代码、价格、涨跌幅，不显示股票全名和涨跌额
- 字体使用 Windows 系统「宋体」点阵字形，实线、无抗锯齿，统一 `#808080` 灰色，不加粗
- 只有第一列（代码）响应拖动和右键；价格、涨跌幅列点击会穿透到下层窗口
- 第一列的命中层约为 0.4% 灰度（视觉上接近 0.2% 黑），基本不可见
- 右键菜单：刷新、设置、置顶、锁定位置、开机自启、退出
- 记住位置、字号、自选列表、置顶/锁定状态
- 断网时保留上一次报价，不闪退
- 纯 Python 标准库（tkinter），无需安装第三方包

## 启动

### 直接运行 exe（推荐，无需 Python）

从 [Releases](https://github.com/popsicle256/goldinfo/releases/latest) 下载 **`GoldInfo.exe`**，双击运行。

首次启动会在 exe 同目录生成 `config.json`，自选、位置、字号都保存在这里；移动 exe 时把 `config.json` 一起带上即可保留设置。

- 单文件版首次启动需要解压到临时目录，约 1–2 秒，之后正常
- 未签名 exe 可能触发 SmartScreen / 杀毒软件提示，选择「仍要运行 / 允许」即可
- 开机自启同样在右键菜单里勾选

### 源码方式

双击 **`启动行情监控.vbs`**（无控制台窗口）。

也可以命令行运行：

```bat
pythonw app.py
```

首次启动默认监控：上证指数、江西铜业、伦敦金现、伦铜。

> 如果双击 VBS 没反应，请确认 Python 已加入 PATH；或直接运行 `python app.py` 看报错。

## 显示规则

第一列取代码后 4 位：

| 代码 | 显示 |
| --- | --- |
| `sh000001` 上证指数 | `0001` |
| `sh600362` 江西铜业 | `0362` |
| `sz300750` 宁德时代 | `0750` |
| `hf_XAU` 伦敦金现 | `XAU` |
| `hf_CAD` 伦铜 | `CAD` |

第二列为价格，第三列为涨跌幅。

## 设置

在第一列代码上 **右键 → 设置…**（只有代码列响应，价格/涨跌幅列会穿透到下层）。

代码格式：

| 输入 | 含义 |
| --- | --- |
| `600362` | 沪市股票，自动补 `sh` |
| `000001` | 深市平安银行，自动补 `sz` |
| `300750` / `430047` | 创业板 / 北交所 |
| `sh000001` | 上证指数（注意：`000001` 默认指平安银行） |
| `sz399001` / `sz399006` | 深证成指 / 创业板指 |
| `hf_XAU` | 伦敦金现（美元/盎司） |
| `hf_CAD` | 伦铜（美元/吨） |
| `hf_HG` | 美铜（备用） |

也支持别名：`上证指数`、`深证成指`、`沪深300`、`伦敦金`、`伦铜` 等。
设置框里可以一次粘贴多个代码（逗号/空格分隔）。

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `F5` | 立即刷新 |
| 拖动第一列代码 | 移动窗口 |
| 右键第一列代码 | 打开菜单/设置 |
| `Ctrl+Q` | 退出 |

## 数据源

- A 股 / 指数 / 外盘：新浪财经 `hq.sinajs.cn`（需要 Referer，程序已带）
- A 股备用：东方财富 `push2.eastmoney.com`
- 行情有延迟，仅供看盘参考，不构成投资建议；休市时显示最近一笔报价

## 配置说明

`config.json` 主要字段：

```json
{
  "symbols": ["sh000001", "sh600362", "hf_XAU", "hf_CAD"],
  "interval": 3,
  "font_size": 10,
  "topmost": true,
  "locked": false,
  "x": 1490,
  "y": 265
}
```

- 背景固定透明，字体固定灰色，不提供透明度/幽灵模式/简洁模式
- `x` / `y`: 窗口位置，`null` 表示自动放在右上角

## 开机自启

右键菜单勾选 **开机自启**，会在

```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\GoldInfoMonitor.bat
```

写入启动脚本。取消勾选即删除。

## 常见问题

**窗口不见了？**
程序没有标题栏和任务栏图标，只显示几行灰色文字；如果文字正好落在浅色壁纸/窗口上，可能不太明显。请找到第一列代码，在代码上右键即可设置或退出。也可以在任务管理器中结束 `pythonw.exe`，删除 `config.json` 后重新启动恢复默认位置。

**行情不刷新 / 显示 `--`？**
检查网络能否访问 `hq.sinajs.cn`。公司代理或安全软件可能拦截；可换网络或稍后重试。

**为什么 `000001` 显示的是平安银行而不是上证指数？**
`000001` 是深市股票代码，上证指数请写 `sh000001`。

**伦铜价格单位？**
新浪 `hf_CAD` 为 LME 铜，美元/吨；伦敦金现 `hf_XAU` 为美元/盎司。
